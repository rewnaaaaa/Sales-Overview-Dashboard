# Sales Overview Dashboard

## 📌 Project Overview
An interactive Excel dashboard designed to analyze sales performance, track total revenue, order trends, and key business metrics to support data-driven decision-making.

## 📊 Key Features & Analysis
- **Data Cleaning & Transformation:** Cleaned raw data using Power Query, handled missing values, and structured data types.
- **Data Modeling:** Created data relationships and metrics using DAX/PivotTables.
- **Interactive Dashboard:** Designed visual charts, key performance indicators (KPIs), and dynamic slicers.

## 🛠️ Tools Used
- **Microsoft Excel** (Power Query, Pivot Tables, Data Analysis)
